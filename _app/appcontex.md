# Cartella `app/`

Contiene le pagine principali del gestionale, i layout condivisi e le route API (Next.js "app router").
Ogni sottocartella rappresenta una pagina o una sezione dell’applicazione.  
All’interno della sottocartella `api/` sono definite le API endpoint (serverless functions) locali all’app.

Aggiungi qui solo pagine, layout e API specifiche di Next.js.
